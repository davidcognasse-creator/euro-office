Vous avez accès à Euro-Office ? Ce module vous rend opérationnel·le. Bonne nouvelle : si vous avez déjà utilisé une suite bureautique en ligne, vous ne serez pas dépaysé·e.

## Les trois éditeurs

Euro-Office réunit trois applications, accessibles depuis votre plateforme :

- **Documents** (traitement de texte, type `.docx` / `.odt`) ;
- **Feuilles de calcul** (tableur, type `.xlsx` / `.ods`) ;
- **Présentations** (diaporamas, type `.pptx` / `.odp`).

Tous trois s'ouvrent dans le navigateur, avec un ruban d'outils classique : mise en forme, insertion d'images et de tableaux, styles, etc.

## Créer et ouvrir un document

1. Depuis votre espace (Nextcloud ou autre), cliquez sur **Nouveau** puis choisissez le type de document.
2. Pour ouvrir un fichier existant, **importez-le** ou cliquez simplement dessus : Euro-Office gère nativement les formats Microsoft et ouverts.
3. L'enregistrement est **automatique** au fil de l'édition. Vous pouvez aussi exporter en PDF à tout moment.

## Collaborer en temps réel

C'est le point fort d'Euro-Office. Pour travailler à plusieurs :

1. Ouvrez un document et utilisez le bouton **Partager** de votre plateforme.
2. Donnez à vos collègues un accès en **lecture** ou en **édition**.
3. Chacun voit, en direct, le **curseur et les modifications** des autres.

Quelques fonctions clés de la collaboration :

| Fonction | À quoi ça sert |
| --- | --- |
| **Commentaires** | Laisser une remarque sur un passage sans modifier le texte |
| **Suivi des modifications** | Proposer des changements, acceptés ou refusés ensuite |
| **Historique des versions** | Revenir à un état antérieur du document |
| **Comparaison** | Visualiser les différences entre deux versions |
| **Messagerie intégrée** | Discuter pendant l'édition, sans quitter le document |

## Bien gérer les formats

Point important hérité de l'[actualité du projet](/actualites/controverse-ooxml-libreoffice/) : par défaut, Euro-Office enregistre au format Microsoft (OOXML). Selon votre politique documentaire, vous pouvez vouloir privilégier les **formats ouverts (ODF)** :

- Pour un document destiné à durer ou à être archivé : préférez **ODT / ODS / ODP**.
- Pour un échange avec des interlocuteurs sous Microsoft Office : **DOCX / XLSX / PPTX** assure la compatibilité.
- Pour une diffusion en lecture seule : exportez en **PDF**.

Les administrateurs peuvent souvent **définir le format par défaut** au niveau du serveur, afin d'harmoniser les pratiques de toute l'organisation.

## Cinq bonnes pratiques pour démarrer

1. **Commencez petit.** Choisissez une équipe pilote avant un déploiement général.
2. **Formez en 30 minutes.** L'interface est familière ; une courte démo suffit souvent.
3. **Définissez une politique de formats** claire (quand ODF, quand OOXML, quand PDF).
4. **Testez vos modèles** (en-têtes, tableaux, présentations type) pour vérifier le rendu.
5. **Remontez les bugs.** Le projet est jeune et communautaire : vos retours sur le dépôt officiel font progresser l'outil.
